HTML Learning Essentials

HTML describes the meaning and structure of a web page. CSS controls appearance, and JavaScript adds behaviour.

Text | Content | Forms | Checklist

1. Text, meaning, and attributes

Use headings in order: one <h1> for the page topic, then <h2> and <h3> for sections.

Strong means important text. Emphasis changes the meaning or stress of text. Use <b> and <i> only when their visual distinction has no meaning.

An attribute adds information to an element. For example, this external link has an href destination.

Special characters can be written with entities: &copy; (copyright), &amp; (ampersand), and &lt; (less-than sign).

2. Common content elements

Lists

Put every list item inside <li>. Use an unordered list when order does not matter:

  • Milk
  • Bread
  • Fruit

Use an ordered list when the sequence matters:

  1. Write the HTML structure.
  2. Add meaningful content.
  3. Check it in a browser.

Images

Images need helpful alternative text. If an image is purely decorative, use an empty alt="".

Tables

Use tables for data, not page layout. A caption and table headings make data easier to understand.

3. Forms and user input

Every input needs a visible <label>. Matching its for value to the input id helps people using assistive technology.





4. Essential habits

  • Start every page with <!doctype html> and set the document language with lang.
  • Keep page information in <head>; put visible content in <body>.
  • Choose elements for their meaning: <header>, <main>, <section>, <article>, <footer>, and <nav>.
  • Use CSS for colours, fonts, spacing, and layout—avoid deprecated tags such as <font> and <center>.
  • Write meaningful link text, alt text, labels, titles, and heading structure for accessibility.
  • Validate your markup with the W3C HTML Validator.
