# CSS Learning Journey

This is a revision path for someone who already knows basic CSS.

## 1. Refresh layout

Revisit Flexbox, Grid, sizing, responsive breakpoints, positioning, and the box model. Rebuild a card grid and a responsive two-column page.

## 2. Refresh maintainability

Review specificity, CSS variables, naming, component boundaries, accessibility states, and browser DevTools debugging.

## 3. Learn CSS Modules

Practice converting a component into a `.module.css` file. Focus on local scope, conditional classes, pseudo-classes, and shared global tokens.

## 4. Learn Tailwind separately

Learn the utility groups, responsive prefixes, state variants, configuration, and when to extract reusable components. Use [the Tailwind guide](./tailwind.md) as the quick reference.

## 5. Compare approaches

Implement the same small UI with plain CSS, CSS Modules, and Tailwind. Compare readability, reuse, customization, and build-time behavior.

## 6. Revisit through projects

- Responsive portfolio section
- Product card and grid
- Form with validation states
- Dashboard layout

For each project, inspect the result at mobile, tablet, and desktop widths and verify keyboard focus styles.
