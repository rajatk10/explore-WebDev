# CSS Revision Notes

Short references for revising CSS in frontend projects.

## Files

- [CSS refresher](./css-refresher.md) — layout, responsive design, and useful patterns.
- [CSS Modules](./css-modules.md) — locally scoped styles in component-based apps.
- [Tailwind CSS](./tailwind.md) — a separate quick guide to utility-first styling.
- [Learning journey](./learning-journey.md) — a practical path from CSS revision to framework usage.

## Choosing an approach

| Approach | Good fit |
| --- | --- |
| Plain CSS | Global styles, design tokens, and simple pages |
| CSS Modules | Component-specific styles with normal CSS syntax |
| Tailwind CSS | Fast composition using utility classes |
| Component library | Standardized UI components and accessibility patterns |
